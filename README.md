# EMV Android SDK: documentation and issues

This repository holds the public documentation and the issue tracker for the EMV Android SDK. It does not contain the SDK's source code or binaries. The SDK is commercial software: licensed customers receive it through authenticated, signed delivery.

- **Documentation:** https://bsreeram08.github.io/emv-android-sdk/ (source in [`docs/`](docs/))
- **Bugs and questions:** [Issues](https://github.com/bsreeram08/emv-android-sdk/issues). Never post card data.
- **Licence enquiries:** open an [access request](https://github.com/bsreeram08/emv-android-sdk/issues/new?template=access.yml).
- **Security problems:** report them privately (Security tab → Report a vulnerability), not in a public issue.
